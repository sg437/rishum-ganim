- **סמל השיבוץ מהעירייה — התראה אוטומטית ב"לטיפול"**: ההשוואה קיימת (עירייה ← "השוואת סמלי מוסד בלבד"), אבל תוצאת ההשוואה לא נשמרת, ולכן אין עדיין התראה קבועה.
