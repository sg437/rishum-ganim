## שלב 1 — תיקונים ונתוני גן

| מה | איפה |
|---|---|
| הסימון הירוק בתפריט עובר ללשונית הפעילה | ארצי — התפריט העליון/הצדדי |
| מגדר גן **"מעורב"** | עיר: גנים ← כרטיס גן ← "מגדר הגן" · סינון: תיקי התלמידות ← סינון ← "מגדר" · ארצי: תלמידים ושיבוץ מרכזי ← "מגדר" |
| גן **רב-גילאי 3/4/5** | עיר: גנים ← כרטיס גן ← "גיל" |
| **כינוי גן** ו**סמל עירוני** | עיר: גנים ← כרטיס גן ← "זיהוי הגן" · מוצגים בטבלת הגנים (הסמל העירוני — רק בעיר שממלאת אותו) · נקלטים גם בייבוא גנים |
| **חיפוש לפי סמל פנימי / סמל גן / סמל עירוני / כינוי** | עיר: חיפוש בלשונית גנים ובתיקי התלמידות · ארצי: תיבת החיפוש בתלמידים ושיבוץ מרכזי |
| **עריכת תפוסה מהארצי** (קיבולת · רף שיבוץ · מכסת רישיון) | ארצי: ערים וגנים ← עיר ← גן ← "קיבולת · עריכה" · או: רישיון וסייעת ב׳ ← כרטיס גן ← "עריכת תפוסה" |
| **סינון לפי תאריך רישום** ו"נרשמה דרך הקישור" | עיר: תיקי התלמידות ← סינון · ארצי: תלמידים ושיבוץ מרכזי ← "ערוץ רישום" + "רישום מ־ / עד" |

## שלב 2 — קליטה, עזיבה, כללי עיר, סייעת ב׳

| מה | איפה |
|---|---|
| **קלוט במשרד החינוך** — סימון בתיק | עיר: תיק תלמידה ← שיבוץ (ליד "קלוט בעירייה") · סינון "קלוט במשרד החינוך" · סימון קבוצתי: לסמן תלמידות ← "סמן כקלוט במשה״ח" · ארצי: מתעדכן לבד מ"בקרת משרד החינוך" |
| **עזיבה באמצע שנה** + מייל לעירייה ולמשרד החינוך | עיר: תיק תלמידה ← "הערות וסיום" ← "🚪 עזיבה באמצע שנה" ← "📧 שליחת עדכון עזיבה במייל" |
| **כללי העיר ואנשי קשר** — מדיניות השארות (מקום פנוי / חובה), מייל העירייה ומשרד החינוך | עיר: הגדרות ← "כללי העיר ואנשי קשר" |
| **זכאות סייעת ב׳** — רישיון בתוקף + גיל 3/4 + 30 ילדות; התראה על שיבוץ ללא זכאות | עיר: גנים ← כרטיס גן ← "רישיון — בתוקף עד" · שיבוץ צוות (התראה אדומה למעלה) · ארצי: רישיון וסייעת ב׳ ("משובצת ללא זכאות") |
| **"סייעת שנייה" = סייעת ב׳** (תיקון) | בכל המקומות למעלה — אין צורך לשנות שמות תפקידים |
| **אישור הרחבת רף** (אסמכתא) | עיר: גנים ← כרטיס גן ← ליד "רף שיבוץ" |
| **ייבוא גנים ואנשי צוות מהארצי** | ארצי: ייבוא מאקסל ← "מה מייבאים": תלמידים / גנים / אנשי צוות |

## שלב 3 — תיעוד, התראות, טופס אחד, ערעורים, מיילים

| מה | איפה |
|---|---|
| **תיעוד והתכתבות בתיק** — שיחה, הערה, מייל יוצא (עם פרטי התיק), מייל שהתקבל | עיר: תיק תלמידה / תיק איש צוות / כרטיס גן ← "תיעוד והתכתבות" · ארצי: תלמידים ← פתיחת תיק ← "תיעוד והתכתבות" + "📞 תיעוד שיחה / הערה" |
| **📧 דיווח על הרשימה** — מייל אחד לעירייה/לכל גורם עם הרשימה המסוננת | עיר: תיקי התלמידות ← "📧 דיווח על הרשימה" (או לסמן ← "📧 דיווח לגורם") |
| **🔔 לטיפול** — מרכז ההתראות: טופל · המשך טיפול + תאריך ותזכורת · העברה לגורם · יומן · משימות | עיר: לשונית "🔔 לטיפול" (שנייה בתפריט) |
| **תזכורות במייל** ביום היעד | אוטומטי — לגורם המטפל, בעיר ובארצי |
| **פניות וערעורים בעיר** + "התפנה מקום בגן מבוקש" | עיר: תיקי התלמידות ▾ ← "פניות וערעורים" · ארצי: פניות וערעורים |
| **אישור קבלה להורים** על פנייה | ארצי: פניות וערעורים ← תיעוד פנייה ← "לשלוח להורים מייל…" |
| **דורש טיפול לפי נושא** — טיפול, תאריך, העברה, יומן | ארצי: "דורש טיפול" |
| **טופס רישום אחד לכל הערים** — בחירת עיר, תלמידה ממשיכה, גנים לפי גיל, דרכון, צהרון, ביטוח, "לא מחייב" | עיר: כלים ושירותים ← רישום דיגיטלי (קישור כללי / קישור לעיר / קישור לערעור · קישור תשלום ביטוח · "להציע צהרון") |
| **טופס ערעור ציבורי** | הקישור בתחתית טופס הרישום · נקלט אוטומטית בארצי ובעיר |
| **מיילים נכנסים לתיק** (אחרי עדכון הגשר) | ארצי: דורש טיפול ← "מיילים נכנסים" (שיוך ידני כשאין התאמה) · נכנסים ליומן התיק |
