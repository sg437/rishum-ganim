## ד. מה צריך לעשות פעם אחת כדי שהכל יעבוד חי

1. Firebase → Firestore → Rules → להדביק את `firestore.rules` → **Publish** (נוספו כללים ל-`org/hq`).
2. לוודא שהגשר בגרסה `2026-09-02` ומעלה (ping) — המרכזי משתמש ב-`sendMailBulk` ו-`chat` הקיימים; אין צורך בפריסה חדשה בשבילו.
3. לסמן משתמשי מרכז במרשם (הגדרות והרשאות → "הוספת משתמש/ת" בלי עיר).
4. ב"ערוצי רישום": לכל עיר — אופן קליטה/שיבוץ, אחראי/ת קליטה, רכז/ת.
