# חבילת העיצוב של המרכזי — `management.html`

השפה: **מסילה רכה · Warm Rail**.
נפרד לחלוטין מחבילת העיצוב של הערים ב-`docs/design/`. ראה ההערה ב-`management.html:31-35`.

## מה קובע

| קובץ | תפקיד |
| --- | --- |
| `HANDOFF.md` | **המפרט הקובע.** נכתב אחרי בניית שני המסכים הראשונים. בסופו טבלת הפערים מול `DESIGN-SPEC.md`. |
| `DESIGN-SPEC.md` | המפרט המוקדם, מתוצר שלב ב'. חלוק על `HANDOFF.md` ב-13 ערכים; טרם הוכרע מי מהם קובע. |
| `Home.dc.html` | לוח הבית — bento grid, רישום ארצי, חריגים, תורי עבודה, פיד יומי. |
| `Students.dc.html` | תלמידים ושיבוץ מרכזי — טבלת תיקים, חריגים ורשימת המתנה, כרטיס תלמיד. |
| `Directions.dc.html` | דף השפה החזותית: סרט, מסילה, תחנות, נורות סטטוס. |
| `support.js` | זמן הריצה של הקנבס. נוצר אוטומטית — לא לערוך. זהה לקובץ שבחבילת הערים. |
| `github.md` | יומן הסנכרון של פרויקט קלוד דיזיין מול המאגר. |

## חקירות מוקדמות — אינן המפרט

`Board` · `DirTrack` · `Index` · `Palettes` · `Soft` · `StudentsFrame` · `Track2` · `Track3` · `Track4`

כיוונים שנבדקו בפלטות אחרות לפני שנבחרה "מסילה רכה". נשמרו לתיעוד בלבד.
אין לגזור מהם ערכים ואין לממש מהם.

## פתיחה

הקבצים נפתחים ישירות בדפדפן מתוך התיקייה הזו. כל `.dc.html` טוען את `./support.js`
שלצידו ואת הגופנים מ-`../../fonts/`, ולכן **חייבים להישאר שטוחים כאן** — העברה
לתת-תיקייה תשבור את שני הנתיבים.

## אזהרה

הקבצים הם הפניות עיצוב, לא קוד production. הם משתמשים במוסכמות הקנבס
(`style-hover`, `style-focus`, `sc-for`, `sc-if`) שאינן HTML תקני ונשענות על
`support.js`. במימוש בתוך `management.html` הן מתורגמות לכללי CSS ולוגיקה אמיתיים.
