# מערכת רישום וקליטת תלמידות 🎒

אפליקציה עצמאית לניהול רישום וקליטת תלמידות לגני הילדות — תיק לכל ילדה, ניהול גנים, מסמכים, סינונים, דוחות ואחוזים.

> **סטטוס:** גרסה ראשונה עובדת (MVP). כל הנתונים נשמרים במכשיר (בדפדפן). מוכן לחיבור Google Drive בשלב הבא.

## איך מריצים
פותחים את `index.html` בדפדפן (מחשב או טלפון). אין צורך בהתקנה או שרת.

## מה כבר עובד (רץ לבד בדפדפן)
- **תיקי תלמידות** — שם, משפחה, ת"ז, תאריך לידה, שם אם/אב, כתובת (רחוב/בניין/עיר), גן משובצת, גיל, מועד רישום, נרשמה על ידינו, קלוט בעירייה.
- **מסמכים** עם וי לכל אחד: נספח · צילום ת"ז · תקנון.
- **שונות** — הורים גרושים (אישור מהאב/אם), ילדת חוץ (הסדר תשלום מול הרשות), ילדת השארות (מסמך השארות).
- **סימון "סיימה גן"** — בסימון אחד יוצאת מהרשימה.
- **גנים** — סמל פנימי, סמל הגן, גננת, גיל, כתובת, אזור, טלפונים (גן/בית/נייד גננת/נייד סייעת), סייעת, קיבולת, הפעלה/כיבוי גן.
- **דוחות ואחוזים** — סה"כ נרשמות, ממוצע לגן (מתעדכן אוטומטית), אחוז לכל גן, פילוח מועדים א׳/ב׳/ג׳/סופי, בחירה לפי אזורים, ומחשבון תחזית באחוזים לפי שנה קודמת.
- **עירייה** — הדבקה/העלאת רשימת ת"ז וסימון אוטומטי (VLOOKUP) של "קלוט בעירייה" לפי ת"ז.
- **ייצוא** — לאקסל (CSV עם עברית תקינה) ול-PDF (הדפסה) לפי סינון.
- **הנהלה** — ספר טלפונים לפי אגפים.
- **הגדרות** — ניהול שנים (תשפ"ז/תשפ"ח…), מעבר שנה עם קידום גיל 3→4 ואיפוס מסמכים, נתונים היסטוריים למחשבון האחוזים, יעד מספר גנים (29↔28), גיבוי/שחזור.

## מה מתוכנן לשלב הבא (דורש חיבור חשבון Google)
- פתיחת תיקיית Drive אוטומטית לכל ילדה, לפי שנה עברית (תשפ"ז / תשפ"ח…) עם שם + ת"ז.
- סנכרון המסמכים עצמם ל-Drive.

## מבנה
- `index.html` — האפליקציה המלאה (קובץ עצמאי אחד).
- `app-artifact.html` — אותה אפליקציה בפורמט להצגה כדף חי (Artifact).

## הערה על אחסון
בגרסה הזו הנתונים נשמרים בדפדפן של המכשיר בלבד (localStorage). לשיתוף בין כמה משתמשים/מכשירים — נדרש שלב חיבור לשרת/דרייב. מומלץ לייצא גיבוי (טאב "הגדרות") מדי פעם.
